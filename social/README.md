# Social (X) drafts

Generated by `/social watch`, `/social release` and `/social resolved` (`prompts/S_social.md`). Drafts are reviewed, edited and posted **by hand**; nothing is posted automatically.

- `drafts/` — one file per run.
- `watch_log.csv` — every signal that contradicted a frozen forecast, with direction and source. The learning loop checks later whether these signals were right.

Stages 03–05 must not read this folder (CLAUDE.md rule 3.8): it quotes official forecasts.
