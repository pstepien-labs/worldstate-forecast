# Expert input

Responses to `reviews/2026-Q4_expert_packet.md`, one file per response: `YYYY-MM-DD_<field>.md`. Summarise the response in your own words. Name the expert only with their consent. Record their importance ratings as a table: question ID, impact, decision.

The quarterly review reads this folder (`prompts/Q_quarterly_review.md`, task 0). It computes the agreement between expert and project ratings (weighted kappa on `impact`). It also turns nominations into the quiet-but-important list (`world_model/quiet_list.md`).
